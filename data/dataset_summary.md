# Dataset Summary

> ⚠️ This file described the **withdrawn** `v1.0` archive. The figures below are the
> corrected ones for release `v1.1`. For what was wrong with `v1.0` and why, see
> [../CORRECTION.md](../CORRECTION.md).

## NSL-KDD with label-blind synchronization features (v1.1)

| Property | Value |
|----------|-------|
| Source | NSL-KDD, University of New Brunswick (real network traffic) |
| Split | `KDDTrain+` 125,973 rows · `KDDTest+` 22,544 rows |
| Features | 59 columns: 41 network + `label` + `is_attack` + 8 synchronization + 8 randomized control |
| Attack rate | 46.5% in `KDDTrain+` — Normal 53.5%, DoS 36.5%, Probe 9.3%, R2L 0.8%, U2R 0.04% |
| Size | ~60 MB uncompressed |
| Generated by | `build_clean_dataset.py` — never reads the `label` column |

### Feature categories

| Category | Count | Description |
|----------|-------|-------------|
| Network flow | 41 | Duration, bytes, protocols, services, host/service rates |
| Synchronization | 8 | `sync_delay_ms`, `sync_jitter_ms`, `sync_accuracy_score`, `update_frequency_hz`, `convergence_time_ms`, `sync_reliability`, `temporal_consistency`, `sync_status_binary` |
| Randomized control | 8 | `rnd_*` — same code path, shuffled inputs; a no-signal baseline |
| Target | 2 | `label` (23 classes), `is_attack` (binary) |

### Leak checks (RandomForest, `KDDTrain+` → `KDDTest+`)

| Input | Accuracy | AUC |
|---|---|---|
| Synchronization features alone | 71.53% | 0.8273 |
| Randomized control alone | 47.59% | 0.5042 |

No column has an absolute Pearson correlation above 0.8 with the target.

## Withdrawn in v1.0

| Removed | Reason |
|---|---|
| `is_malicious` | Pearson *r* = +1.000 with the target — an exact duplicate of the label |
| `severity_level` | Non-null only for attack rows |
| 20-column DT feature block | Generated with access to the label (`anomaly_detection_score` *r* = +0.939, `twin_health_score` *r* = −0.861); regenerated label-blind in v1.1 |
| Synthetic DT batches | Same label-derived columns; 50,000 samples, not the 125,000 previously stated. Not re-released |
